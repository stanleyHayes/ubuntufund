# Homepage artwork

Generated September 5, 2026 with the built-in image generation tool for Ujimora. These are editorial illustrations, not photographs of actual customers or completed campaigns.

- `community-garden.jpg`: contemporary Ghanaian neighbors planning a garden in a courtyard. Hero image.
- `community-learning.jpg`: Ghanaian adults organizing books and learning supplies. Organizations section.

Direction: textured gouache and dimensional cut-paper, forest green, sage, ochre, clay and ivory; dignified everyday collaboration; no logos or text. JPEG derivatives are 1536 by 1024; original PNGs remain in the Codex generated-images folder.

Original SVG linework and CSS 3D sculptures live in `src/components/art`. Motifs are original decorative geometry and are not claimed as traditional symbols. The sculptures support mouse tilt, click/tap rotation and left/right arrow keys; reduced-motion uses a static orientation.
